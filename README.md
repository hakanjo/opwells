# OPWELLS v. 1.0.0
OPWELLS is a questionnaire based on 10 questions for measuring older persons' wellbeing. This web application aims to assist in the analysis of OPWELLS survey responses.

## Updating the application text
The text (and translations) in the application is controlled through the locales file (`data/locales.yml`). To update the text, simply edit the locales file and re-deploy the application.

The longer sections of text have markdown enabled and will accept stadard markdown syntax for, e.g., bold, italics, and links (see https://www.markdownguide.org/basic-syntax/).
